# 발행 전 필수 검수 체크리스트

`SKILL.md` 5단계(교육적/법적 검수)에서 이 목록을 항목별로 통과/실패 표시하여
`output/<run>/review_report.md`에 기록합니다. 하나라도 실패하면 자동으로 "발행 보류"
상태로 표시하고 원장님께 사유를 명시합니다.

## 1. 학원법 / 광고 규정
- [ ] 성적·합격·등급을 보장하거나 확정하는 표현이 없는가 ("무조건", "100%", "보장" 등)
- [ ] 타 학원을 직접적으로 비방·비교하는 내용이 없는가
- [ ] 학원 상호, 주소 등 표시 의무 사항이 필요한 경우 포함되어 있는가 (원장님 확인 필요 항목은
      `[확인필요]` 태그로 남김)
- [ ] 가격/수강료 관련 오해를 살 수 있는 표현이 없는가

## 2. 개인정보 / 초상권 (미성년자)
- [ ] 사용된 모든 사진이 `config/photo_manifest.json`에서 `consent: true`로 표시된 항목인가
- [ ] 사진 속 학생의 실명, 학교명이 캡션/본문에 노출되지 않는가
- [ ] 얼굯이 클로즈업되어 특정 개인이 쉽게 식별되는 사진을 과도하게 사용하지 않는가 (뒷모습,
      단체 활동 사진 우선 권장)

## 3. 교육 내용 정확성
- [ ] 언급된 학년/단원/교육과정 용어가 해당 학년 교육과정과 일치하는가
- [ ] 시험 일정, 개정 교육과정 등 시의성 정보가 최신 사실과 맞는가 (모호하면 `[확인필요]` 표시)
- [ ] 수학적 설명(공식, 풀이) 자체에 오류가 없는가

## 4. SEO / 플랫폼 정책
- [ ] 동일 키워드를 부자연스럽게 반복(키워드 스터핑)하지 않는가 — 네이버 저품질 문서 판정 위험
- [ ] 제목이 클릭베이트성 과장 없이 실제 내용을 반영하는가
- [ ] 이미지에 적절한 대체 설명(alt/캡션)이 있는가

## 결과 표기 규칙
- 전 항목 통과 → `발행 가능 (원장님 최종확인 대기)`
- 1개 이상 `[확인필요]` → `보류 — 원장님 확인 필요` + 구체적 항목 명시
- 1개 이상 명확한 위반 → `반려 — 수정 후 재검수`
