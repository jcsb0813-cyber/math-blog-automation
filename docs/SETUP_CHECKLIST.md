# 실행 전 준비 체크리스트

이 4가지가 끝나야 파이프라인이 실제로 돌아갑니다. 순서대로 진행하세요.

## 1. GitHub 계정 + 이 리포지토리 업로드
- [ ] github.com에서 무료 계정 생성 (이미 있다면 스킵)
- [ ] 계정 생성되면 저에게 알려주세요 — 이 폴더를 그 계정의 새 저장소로 올려드립니다.
- [ ] 저장소는 **Private**로 만듭니다 (학생 관련 정보/사진 경로가 포함되므로 절대 Public 금지)

## 2. 네이버 오픈API 키 (무료)
- [ ] https://developers.naver.com/apps/#/register 에서 애플리케이션 등록
- [ ] 사용 API: "검색" (블로그/뉴스), "데이터랩(검색어트렌드)" 체크
- [ ] 발급된 `Client ID`, `Client Secret`을 저에게 전달 (또는 GitHub 저장소의
      Secrets에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`으로 직접 등록해도 됩니다)
- [ ] **절대 코드에 직접 적지 않고, 환경변수/Secrets로만 관리합니다**

## 3. Canva 브랜드 템플릿 (카드뉴스용)
- [ ] 학원 로고, 색상, 폰트가 들어간 "카드뉴스 4장" 기본 템플릿을 Canva에서 1개 준비
      (없으면 이번 세션에서 Canva 연동으로 같이 만들어드릴 수 있습니다 — 말씀해주세요)
- [ ] 템플릿이 준비되면 어떤 템플릿을 쓸지 말씀해주세요 (자동화가 이후 회차마다 재사용합니다)

## 4. 학원생활 사진 매니페스트
- [ ] `config/photo_manifest.example.json` 형식을 참고해서 실제 동의받은 사진들을
      `config/photo_manifest.json`으로 정리 (이 파일은 git에 올리지 않습니다 — `.gitignore` 처리됨)
- [ ] 사진 원본은 구글드라이브 등에 두고, 매니페스트에는 경로/링크와 태그만 기록
- [ ] 동의서가 없는 사진은 절대 등록하지 않습니다 (`consent: true`는 실제 동의서가 있을 때만)

## 준비 끝나면
"준비 다 됐어" 라고 말씀해주시면, 실제 값들을 연결하고 `/blog-auto 중2` 같은 식으로
첫 회차를 돌려보겠습니다. 하나씩만 준비되어도 그 범위 안에서 먼저 테스트해볼 수 있으니
전부 갖춰질 때까지 기다리지 않아도 됩니다.
