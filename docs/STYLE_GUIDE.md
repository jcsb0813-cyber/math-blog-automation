# 문체 가이드 — 육아맘 블로거 + 교육 파워블로거 톤

이 문서는 글쓰기 단계(`SKILL.md` 2단계)에서 Claude가 항상 참조하는 톤 기준입니다.
초안이 어색하면 이 문서를 먼저 다듬으세요. 실제 원장님이 좋아하는 블로거 글 2~3개를
`docs/reference_posts/`에 넣어두면 더 정확하게 흡수합니다 (아직 폴더 없음, 예시 글이
생기면 만들어서 채워주세요).

## 브랜드 기준 (확정)
- 학원명: **민락동 쎈수학앤논술학원**
- 메인 컬러: **노란색** — 카드뉴스 등 모든 시각 자료에 포인트 컬러로 사용
- 카드뉴스는 항상 **1:1(정사각형) + 9:16(세로)** 두 사이즈를 세트로 제작 (`SKILL.md` 4단계 참고)

## 육아맘 블로거 요소
- 1인칭, 아이를 키우는 학부모 입장에서 말하듯 시작 ("저희 반 OO이가...", "요즘 학부모님들
  많이 물어보시는 게...")
- 완벽한 정보 나열이 아니라 **공감 → 고민 인정 → 해결 실마리** 순서
- 문장은 짧게, 구어체 종결("~하더라구요", "~더라고요", "~해보세요") 섞기. 단, 과한 이모티콘/
  느낌표 남발은 피함 (신뢰도 저하)
- 광고성 단정 표현("무조건", "100% 보장") 금지 — `COMPLIANCE_CHECKLIST.md` 참고

## 교육 파워블로거 요소
- 학년별 교육과정 용어를 정확히 사용 (예: 중2 "일차함수", 중3 "이차방정식과 이차함수")
- 근거 있는 정보 우선: 교육과정 개정 사항, 시험 기간, 단원평가 시기 등 시의성 있는 사실 인용
- 소제목(H3) 3~4개로 구조화, 각 소제목 아래 실용적 팁 1~2개
- 마무리에 "우리 학원은 이렇게 도와줍니다" 자연스러운 연결 (직접적 홍보 문구는 지양,
  경험/사례 중심 서술)

## 글 구조 템플릿
1. 공감형 도입 (2~3문장) — 이번 주제가 왜 학부모의 고민인지
2. 핵심 정보 섹션 1~2개 (소제목) — 검색 트렌드에서 뽑은 핵심 질문에 답
3. 학원생활 사례 섹션 — 사진 삽입 지점, 실제 수업/학생 에피소드 (매니페스트에서 선택된 사진과 자연스럽게 연결되는 문장)
4. 마무리 — 다음 행동 제안 (상담 신청, 다음 글 예고 등), 과장 없이

## 절대 쓰지 않는 표현
- "100% 성적 향상", "무조건 합격", "1등급 보장" 등 결과를 보증하는 표현
- 특정 학생의 실명, 학교명 노출
- 타 학원 직접 비방/비교
