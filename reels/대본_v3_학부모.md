# 학부모 대상 릴스 대본 v3 (유튜브 쇼츠 조사 반영)

근거: `유튜브쇼츠_조사_2026-10.md`, 기획안 `기획안_v2.md`의 원칙(독자는 학부모 한 명 / 영상 하나 = 메시지 하나 / 마지막은 행동 하나).
형식: `훅(2줄, 2.4초)` → `카드 6장(각 2줄, 2초)` → `마무리(2줄)`. 학원 선생님이 어머님께 말하는 존댓말.

## v2에서 바꾼 것 (조사 반영)
1. **훅을 "정보 예고"에서 "장면·변화·숫자" 한 줄로.** 조사에서 방법/팁형보다 사람·상황·변화형이 강했음.
2. **카드 1이 훅을 바로 이어받음** (궁금증을 끊지 않고 약속 → 카드 6에서 회수).
3. **비교 구도 추가** (학년/전·후): 조사에서 비교형이 수학 쇼츠에서 강했음.
4. **"내 아이 얘기" 말투.** 학부모 대상 정보형은 반응이 낮았음 → "~해야 합니다" 대신 "~하는 집이 많아요 / 이렇게 해보세요".
5. 길이: 조사상 길수록 유리한 경향이라 카드 6장은 유지하되, 시험용으로 **각 형식 1개는 카드 8장(약 20초)** 버전도 표시(★). 인사이트로 완주율·저장 비교 권장.

> 모든 `verify` 항목은 발행 전 원장님 확인용입니다. 실제 학원 운영과 다르면 고쳐주세요. 수치(점수 변화 등)는 실제 사례가 있을 때만 쓰고, 없으면 "빵점→만점" 대신 일반 표현으로 바꾸세요.

## A. 수업 엿보기 (신뢰·상담) — "학원 가면 뭐해요?"

### A1. 초등 · "5학년 아이가 칠판 앞에 서면"
- 훅: `5학년 아이가 칠판 앞에서` / `제일 먼저 하는 말이 뭘까요?`
- 카드
  1. `어머님, 궁금하시죠?` / `오늘 수업을 보여드릴게요`
  2. `① 어제 배운 것 Test` / `기억하는지 먼저 확인해요`
  3. `② 화면 속 도전 문제` / `같이 읽고 먼저 생각해요`
  4. `③ 칠판 앞에 나와서` / `내 방법으로 직접 풀어요`
  5. `제일 먼저 하는 말은` / `"저는 이렇게 풀었어요"`
  6. `정답보다 먼저 자라는 건` / `설명하는 힘이에요`
- 마무리: `우리 아이 수업이 궁금하면` / `프로필 링크로 편하게 상담`
- verify: 수업 단계(Test→도전 문제→칠판 풀이)와 대사는 실제 수업에 맞게 수정

### A2. 중등 · "중2 수학, 한 시간 동안"
- 훅: `중2 아이가 수학학원에서` / `한 시간 동안 하는 일`
- 카드
  1. `숙제 검사만 하는 줄` / `아셨다면 오해예요`
  2. `① 틀린 문제 다시 보기` / `왜 틀렸는지부터 찾아요`
  3. `② 새 개념은 짧게` / `바로 문제에 써봐요`
  4. `③ 풀이를 말로 설명` / `설명이 막히면 이해가 덜 된 곳`
  5. `④ 오늘의 마무리 Test` / `집 가기 전에 확인해요`
  6. `집에서는 이것만 물어봐 주세요` / `"오늘 뭐가 제일 어려웠어?"`
- 마무리: `수업 방식이 궁금하시면` / `프로필 링크로 상담`
- verify: 수업 순서·시간 배분 실제와 다르면 수정

### A3. 고등 · "고1 수학, 첫 한 달"
- 훅: `고1 첫 달에` / `수학학원에서 제일 먼저 보는 것`
- 카드
  1. `점수보다 먼저 보는 건` / `중학교 때 빠진 부분이에요`
  2. `① 진단 Test` / `어디서 막히는지 찾아요`
  3. `② 빠진 개념만 채우기` / `전부 다시 하지 않아요`
  4. `③ 오답 노트` / `틀린 이유를 한 줄로 써요`
  5. `④ 첫 시험 전 점검` / `시간 배분까지 연습해요`
  6. `첫 한 달이 고등 수학` / `3년의 출발점이에요`
- 마무리: `우리 아이 진단이 궁금하면` / `프로필 링크로 상담`
- verify: 진단 Test 운영 여부 확인(없으면 ②~③ 문구 수정)

## B. 공감 (저장·공유) — "우리 애만 이런가요?"

### B1. 초등 · "이거 모르고 3년 시켰어요" ★(8장 시험판)
- 훅: `아는 문제인데 또 틀렸어요` / `이거 나만 몰랐나요?`
- 카드
  1. `어머님만 그런 거 아니에요` / `초등 때 정말 흔한 일이에요`
  2. `실수는 실력 부족이 아니라` / `"확인 습관"이 없어서예요`
  3. `가장 흔한 3가지` / `숫자 옮기기 · 부호 · 문제 안 읽기`
  4. `"조심해!"라고 말하면` / `아이는 방법을 몰라요`
  5. `대신 이것만 시켜보세요` / `푼 뒤 거꾸로 계산하기`
  6. `예) 36÷4=9 이면` / `9×4=36 으로 확인`
  7. `하루 3문제만 해도` / `2주 뒤 실수가 눈에 띄게 줄어요`  ★
  8. `틀린 걸 혼내기보다` / `확인한 걸 칭찬해주세요`  ★
- 마무리: `저장해두고 오늘 한번 해보세요` / `도움 되면 다른 어머님께 공유!`
- verify: "2주 뒤" 같은 기간은 일반적 표현 - 실제 학생 사례 있으면 교체

### B2. 중등 · "중2 수학 점수가 갑자기 떨어졌어요"
- 훅: `중2부터 수학이` / `갑자기 어려워졌다는 아이들`
- 카드
  1. `우리 애만 이런 거` / `아니에요`
  2. `초등 때와 다른 건` / `"계산"이 아니라 "식"이에요`
  3. `문자·식·방정식` / `처음 보는 말이 한꺼번에 나와요`
  4. `점수가 떨어진 게 아니라` / `방식이 바뀐 거예요`
  5. `이렇게 해보세요` / `풀이를 말로 설명하게 하기`
  6. `설명이 막히는 곳이` / `딱 그 아이의 빈틈이에요`
- 마무리: `저장해두고 이번 주에 해보세요` / `비슷한 고민 어머님께 공유!`
- verify: 단원 설명은 일반론 - 학교 진도에 맞게 보강 가능

### B3. 고등 · "공부는 하는데 성적이 안 올라요"
- 훅: `하루 3시간 공부하는데` / `왜 성적이 안 오를까요?`
- 카드
  1. `아이 의지 문제가 아니에요` / `자주 있는 일이에요`
  2. `원인은 대부분 하나` / `푼 문제만 늘고 오답은 그대로`
  3. `푸는 시간 7 : 돌아보는 시간 3`  / `이 비율이 반대인 경우가 많아요`
  4. `틀린 문제 옆에` / `"왜 틀렸나" 한 줄만 쓰기`
  5. `일주일 뒤 같은 문제` / `다시 풀어보기`
  6. `같은 실수가 줄면` / `점수는 따라와요`
- 마무리: `저장해두고 이번 주말에 해보세요` / `도움 되면 공유해주세요`
- verify: "7:3" 비율은 예시 표현 - 학원 지도 방식에 맞게 조정

## C. 체크리스트 (저장) — "엄마가 뭘 해줘요?"

### C1. 초등 · "수학 잘하는 아이 집의 공통점 3가지"
- 훅: `수학 잘하는 아이 집` / `공통점 딱 3가지`
- 카드
  1. `학원 선생님으로서` / `가장 많이 보는 모습이에요`
  2. `① 틀린 걸 숨기지 않는다` / `"틀려도 괜찮아"가 먼저`
  3. `② 풀이를 말로 설명한다` / `"어떻게 풀었어?" 한마디`
  4. `③ 숙제 시간이 정해져 있다` / `오래 말고 꾸준히`
  5. `하지 말아야 할 한 가지` / `점수만 먼저 묻기`
  6. `"몇 점이야?" 대신` / `"뭐가 재밌었어?"`
- 마무리: `저장해두고 오늘 저녁에 써보세요` / `다른 어머님께도 공유!`
- verify: "많이 보는 모습"은 원장님 경험 기반 표현 - 실제 관찰과 다르면 수정

### C2. 중등 · "시험 2주 전, 엄마가 할 일 3가지"
- 훅: `시험 2주 전` / `엄마가 해줄 수 있는 3가지`
- 카드

  2. `① 시험 범위 같이 확인` / `날짜와 단원을 적어두기`
  3. `② 계획은 아이가 짜게` / `엄마는 확인만`
  4. `③ 전날 밤은 일찍 재우기` / `암기보다 수면이에요`
  5. `하지 말 것` / `"왜 이렇게 못 해" 한마디`
  6. `시험 전 아이에게 필요한 건` / `잔소리보다 안심이에요`
- 마무리: `시험 전에 저장해두세요` / `친구 어머님께 공유!`
- verify: 없음 (일반 조언) - 학원 시험 대비 프로그램 있으면 마무리에 언급
