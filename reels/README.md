# 인스타 릴스 만들기

사진 폴더를 넣으면 인스타그램 릴스용 **9:16 세로 영상(1080×1920)**을 만들어 줍니다.
사진 1장당 1초씩, 파일명 순서대로 넘어갑니다.

## 맥에서 쓰기

**처음 한 번만**
1. [python.org](https://www.python.org/downloads/)에서 macOS용 파이썬을 받아 설치
2. 이 저장소를 **Code → Download ZIP**으로 받아 압축 풀기 → `reels` 폴더를 원하는 곳(예: 문서)으로 옮기기
3. `릴스자동감시.command`를 **마우스 오른쪽 클릭 → 열기 → 열기** (처음 한 번만 이렇게 열어야 맥 보안 경고를 통과)
   - "데스크탑 폴더에 접근하려고 합니다" 창이 뜨면 **허용**
   - 첫 실행은 준비 때문에 1~2분 걸립니다

**매번**: `릴스자동감시.command` 더블클릭 → **iCloud Drive**의 `릴스/1번`~`100번` 폴더에 사진을 넣으면 그 폴더 안에 영상이 생깁니다.
(iCloud Drive를 안 쓰면 바탕화면 `릴스` 폴더를 사용)
한 번에 몰아서 만들 때는 `릴스만들기.command` (결과는 `릴스/완성영상/`).

### 아이패드에서 쓰기

1. 아이패드 **파일 앱 → iCloud Drive → 릴스 → 1번** 폴더에 사진 저장
2. 맥이 영상을 만들면 같은 폴더에 `1번.mp4`가 생김 → 아이패드에서 바로 인스타 업로드
3. 맥이 **잠자기/꺼져 있던 동안 넣은 사진도, 맥을 켜면 확인해서 영상을 만듭니다** (아래 로그인 항목 설정 필요)

- 맥 Finder에서 iCloud Drive의 `릴스` 폴더를 오른쪽 클릭 → **"다운로드된 상태로 유지"**를 켜두면 사진이 빨리 내려와서 영상이 더 빨리 만들어집니다.
- **제목 자막**: 폴더에 `대본.txt`를 넣으면 그 내용이 **첫 사진(처음 1초)에만**, 화면 위쪽 1/3 지점에
  노란 띠 자막(나눔바른고딕 Bold)으로 들어갑니다. 대본의 줄바꿈이 자막 줄바꿈이 됩니다.
  ```
  우리 아이 학원생활
  5학년 수업영상
  ```
  영상이 이미 만들어진 폴더에 나중에 `대본.txt`를 넣거나 고쳐도 다시 만들어집니다.
  (`대본.txt`는 맥의 텍스트 편집기에서 **포맷 → 일반 텍스트로 만들기** 후 저장)
- 각 폴더의 `.폴더이름.만든사진목록` 숨김 파일은 "이 사진들로 이미 만들었음" 기록이니 지우지 마세요.

- 아이폰 사진(HEIC)도 그대로 넣으면 됩니다.
- 맥을 켤 때 자동으로 켜지게 하려면: 시스템 설정 → 일반 → 로그인 항목 → `+` → `릴스자동감시.command` 추가
- 맥이 잠자기 상태가 되면 멈춥니다.
- "열 수 없습니다"가 계속 나오면: 터미널을 열고 `bash ` (bash 뒤 한 칸 띄우기)를 입력한 뒤 `.command` 파일을 터미널 창으로 끌어다 놓고 엔터

## 윈도우에서 쓰기 (더블클릭)

**처음 한 번만**
1. [python.org](https://www.python.org/downloads/)에서 파이썬 설치 — 설치 화면에서 **"Add python.exe to PATH" 체크**
2. 이 저장소를 **Code → Download ZIP**으로 받아 압축 풀고 `reels` 폴더로 들어가기

**매번**
1. 바탕화면에 `릴스` 폴더를 만들고 그 안에 `1번`, `2번` … 폴더를 만들어 영상별로 사진을 넣기
2. `릴스만들기.bat` 더블클릭 (다른 위치의 폴더는 이 파일 위로 끌어다 놓기)
3. `릴스\완성영상\1번.mp4`, `2번.mp4` …로 저장되고 폴더가 자동으로 열림

```
바탕화면\릴스\
 ├─ 1번\  (사진 4장)
 ├─ 2번\  (사진 6장)
 └─ 완성영상\
     ├─ 1번.mp4   ← 4초
     └─ 2번.mp4   ← 6초
```

- 폴더는 숫자 순서(1번 → 2번 → 10번), 폴더 안 사진은 파일명 순서
- 자막이 필요한 폴더에만 `대본.txt`를 넣으면 그 영상 첫 1초에 제목 자막 (대본의 줄바꿈 그대로)

## 자동으로 만들기 (폴더 감시)

`릴스자동감시.bat`을 더블클릭해 켜두면, 바탕화면 `릴스` 폴더에 `1번`~`100번` 폴더가 생기고
**사진이 들어온 폴더를 알아서 영상으로 만듭니다.**

- 사진이 없는 폴더는 그냥 기다립니다.
- 사진을 넣으면 **10초 동안 추가가 없을 때** 작업을 시작합니다. 여러 장을 옮기는 도중에는 만들지 않습니다.
- 영상은 **그 폴더 안에** 저장됩니다 (예: `릴스\1번\1번.mp4`).
- 영상을 만든 폴더에 사진을 더 넣거나 바꾸면 영상을 다시 만듭니다.
- 검은 창이 떠 있는 동안만 동작합니다. 끄려면 창을 닫으세요.
- 컴퓨터를 켤 때마다 자동으로 켜지게 하려면: `Win + R` → `shell:startup` 입력 → 열린 폴더에
  `릴스자동감시.bat`의 **바로가기**를 넣어두세요.
- 휴대폰 사진을 바로 넣고 싶으면 `릴스` 폴더를 구글 드라이브/원드라이브 동기화 폴더 안에 두고
  휴대폰에서 그 폴더로 올리면 됩니다 (이때는 bat 파일 위로 그 폴더를 끌어다 놓아 실행).

## 명령어로 쓰기

```bash
pip install -r ../requirements.txt   # 맥은 python3 / pip3
python make_reel.py --photos ./사진폴더                 # 영상 1편
python make_reel.py --photos ./릴스 --fill              # 하위 폴더마다 1편씩 → 릴스/완성영상/
python make_reel.py --photos ./사진폴더 --script 대본.txt --music bgm.mp3 --seconds 1.5
python watch_reels.py --root ./릴스 --create 100    # 폴더 감시 (Ctrl+C 종료)
```

| 옵션 | 설명 |
|---|---|
| `--fill` | 흐린 여백 없이 화면 꽉 채우기 (휴대폰 3:4 사진은 양옆이 조금 잘림) |
| `--seconds` | 사진 1장당 초 (기본 1) |
| `--script` | 자막 대본 txt (노란 띠 자막 + `.srt` 파일 함께 저장) |
| `--first-only` | 대본 첫 줄을 첫 사진에만 표시 (제목처럼) |
| `--music` | 배경음악 (영상 길이에 맞춰 자르고 마지막 1초 페이드아웃) |
| `--position` / `--font-size` / `--font` | 자막 위치(bottom/third/center/top, third = 화면 위쪽 1/3)·크기·폰트 |

## 릴스 비율 팁

- 릴스 전체화면은 9:16, 홈 피드는 4:5 정도, 프로필 격자는 3:4로 가운데만 보입니다 → 중요한 내용은 화면 가운데에.
- 휴대폰 카메라 비율을 9:16(Full)으로 찍으면 잘리는 부분이 없습니다.
