# 인스타 릴스 만들기

사진 폴더를 넣으면 인스타그램 릴스용 **9:16 세로 영상(1080×1920)**을 만들어 줍니다.
사진 1장당 1초씩, 파일명 순서대로 넘어갑니다.

## 윈도우에서 쓰기 (더블클릭)

**처음 한 번만**
1. [python.org](https://www.python.org/downloads/)에서 파이썬 설치 — 설치 화면에서 **"Add python.exe to PATH" 체크**
2. 이 저장소를 **Code → Download ZIP**으로 받아 압축 풀고 `reels` 폴더로 들어가기

**매번**
1. 바탕화면에 `릴스` 폴더를 만들고 그 안에 `1번`, `2번` … 폴더를 만들어 영상별로 사진을 넣기
2. `릴스만들기.bat` 더블클릭 (다른 위치의 폴더는 이 파일 위로 끌어다 놓기)
3. `릴스\완성영상\1번.mp4`, `2번.mp4` …로 저장되고 폴더가 자동으로 열림

```
바탕화면\릴스\
 ├─ 1번\  (사진 4장)
 ├─ 2번\  (사진 6장)
 └─ 완성영상\
     ├─ 1번.mp4   ← 4초
     └─ 2번.mp4   ← 6초
```

- 폴더는 숫자 순서(1번 → 2번 → 10번), 폴더 안 사진은 파일명 순서
- 자막이 필요한 폴더에만 `대본.txt`를 넣으면 그 영상에만 자막 (형식은 `대본_예시.txt` 참고, 한 줄 = 자막 한 줄)

## 명령어로 쓰기

```bash
pip install -r ../requirements.txt
python make_reel.py --photos ./사진폴더                 # 영상 1편
python make_reel.py --photos ./릴스 --fill              # 하위 폴더마다 1편씩 → 릴스/완성영상/
python make_reel.py --photos ./사진폴더 --script 대본.txt --music bgm.mp3 --seconds 1.5
```

| 옵션 | 설명 |
|---|---|
| `--fill` | 흐린 여백 없이 화면 꽉 채우기 (휴대폰 3:4 사진은 양옆이 조금 잘림) |
| `--seconds` | 사진 1장당 초 (기본 1) |
| `--script` | 자막 대본 txt (노란 띠 자막 + `.srt` 파일 함께 저장) |
| `--music` | 배경음악 (영상 길이에 맞춰 자르고 마지막 1초 페이드아웃) |
| `--position` / `--font-size` / `--font` | 자막 위치·크기·폰트 |

## 릴스 비율 팁

- 릴스 전체화면은 9:16, 홈 피드는 4:5 정도, 프로필 격자는 3:4로 가운데만 보입니다 → 중요한 내용은 화면 가운데에.
- 휴대폰 카메라 비율을 9:16(Full)으로 찍으면 잘리는 부분이 없습니다.
