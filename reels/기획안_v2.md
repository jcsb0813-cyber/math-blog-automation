# 릴스 대본 기획안 v2

## 왜 다시 기획했나 (v1의 문제)
- 누구에게 하는 말인지 흐림: 학생에게 하는 공부법인지 학부모에게 하는 정보인지 섞여 있었음
- 한 영상에 메시지가 없음: 정보를 10줄 나열 → 끝나도 "그래서 뭐?"가 남음
- 사진과 자막이 따로 놂: 학원 수업 사진에 소수·분수 팁 자막 → 의미 연결이 없음

## 근거 (확인된 것 / 확인 못 한 것)
- **원장님 계정 실제 반응(보내주신 화면)**: "6학년 학원가면 뭐하나?" 2,578회 > "빵점에서 만점까지" 1,455회 > "4학년 학교시험" 545회 > 퀴즈형 카드뉴스 약 240~250회.
  → 학부모가 가장 궁금한 건 **"학원에서 우리 아이가 뭘 하나"** 와 **변화 이야기**. 정보 나열형은 상대적으로 약함.
- 일반 릴스 자료(블로그, 검증 수치는 아님): 첫 1~3초 훅, 한 영상 한 주제, 저장·공유(DM)가 중요 신호, 소리 없이 보므로 자막 필수, "나만 그런 게 아니구나" 공감이 공유로 이어짐.
- 확인 못 한 것: 학원 업종 릴스의 실제 조회수 데이터, 맘카페 게시글 원문(로그인 필요). 인스타 인사이트의 저장·공유 수로 직접 검증이 가장 정확함.

## 원칙
1. **독자는 학부모(엄마) 한 명.** 말투는 학원 선생님이 어머님께 말하는 존댓말. 아이에게 하는 말 금지.
2. **영상 하나 = 메시지 하나.** 훅에서 약속하고 마지막 카드에서 한 줄로 회수.
3. **사진과 연결되는 형식을 우선**: 어떤 수업 사진이든 어울리는 `수업 엿보기`가 기본.
4. 카드는 6장, 한 카드 = 한 생각(2줄). 정보를 늘어놓지 않고 "순서"나 "이유→방법"이 있게.
5. 마지막은 **행동 하나**: 상담(프로필 링크) 또는 저장·공유.

## 3가지 형식
| 형식 | 학부모 질문 | 구조 | 쓰는 사진 | 목표 |
|---|---|---|---|---|
| 수업 엿보기 | "학원 가면 뭐해요?" | 훅 → 오늘 수업 흐름 ①②③ → 집에서 해볼 한마디 → 상담 | 수업 장면 아무거나 | 신뢰·상담 |
| 공감 | "우리 애만 이런가요?" | 훅 → "아니에요" → 원인 1개 → 해결 2~3개 → 저장·공유 | 공부하는 아이 사진 | 공유·저장 |
| 체크리스트 | "엄마가 뭘 해줘요?" | 훅(N가지) → 항목 → 하지 말 것 → 저장 | 아무거나 | 저장 |

## 한 영상의 모양 (약 16초)
`훅(2.4초)` → `카드 6장(각 2초)` → `마무리(2초)`
