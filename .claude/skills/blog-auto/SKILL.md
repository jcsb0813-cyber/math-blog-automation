# 학원 블로그 자동화 파이프라인

입력: 학년 (예: "중2"). 선택 입력: 특정 주제를 직접 지정하고 싶으면 함께 전달.

이 스킬은 **발행까지 자동으로 하지 않는다.** 마지막 산출물은 원장님이 검토 후
네이버 블로그에 직접 붙여넣어 발행하는 "최종검수용 패키지"다.

## 0단계 — 사전 점검
- `docs/SETUP_CHECKLIST.md`의 필수 항목(네이버 API 키, 사진 매니페스트, Canva 템플릿)이
  준비되어 있는지 확인한다. 없으면 그 항목만 짚어주고 중단한다 — 대충 넘어가지 않는다.
- `config/photo_manifest.json`이 없으면 `config/photo_manifest.example.json`만 있다고
  안내하고, 실제 동의 사진 등록이 먼저 필요하다고 말한다.

## 1단계 — 주제 선정
- `python scripts/topic_research.py --grade <학년>` 실행해서 검색 트렌드/경쟁도 데이터를 얻는다.
- 결과를 바탕으로 후보 주제 3개를 뽑아 각각 1줄 근거(왜 지금 이 주제가 이슈인지)를 붙인다.
- 사용자가 이미 대화에서 방향을 준 경우 그걸 우선한다. 아니면 트렌드가 가장 뚜렷하고
  학원 서비스와 자연스럽게 연결되는 주제 1개를 골라 진행하되, 고른 이유를 한 줄로 밝힌다.

## 2단계 — 본문 작성
- `docs/STYLE_GUIDE.md`의 톤/구조를 따른다.
- 분량: 1500~2200자 (네이버 블로그 최적 체류시간 기준).
- 사진이 들어갈 지점 2곳을 `[PHOTO: <태그>]` 형태로 본문에 표시해둔다 (3단계에서 실제 사진으로 매칭).
- SEO 제목 후보 3개 제시 (핵심 키워드 포함, 클릭베이트 금지).

## 3단계 — 사진 매칭
- `config/photo_manifest.json`에서 `consent: true`이고 만료되지 않았으며, 본문의
  `[PHOTO: <태그>]`와 태그가 겹치는 사진을 선택한다.
- 적합한 사진이 없으면 억지로 끼워 맞추지 말고 "이 태그에 맞는 동의 사진 없음 — 직접 선택 필요"로 표시한다.
- `faces_identifiable: true`인 사진은 캡션에 실명/학교명이 들어가지 않는지 다시 확인한다.

## 4단계 — 카드뉴스 4장 (Canva)
- 본문에서 핵심 메시지 4개를 뽑는다: ①후킹 제목 슬라이드 ②정보 슬라이드 A ③정보 슬라이드 B
  ④학원 안내/CTA 슬라이드.
- 브랜드 기준 (확정, 매번 동일하게 적용):
  - 메인 컬러: **노란색** 포인트
  - 학원명: "민락동 쎈수학앤논술학원"
- Canva MCP 도구로 진행한다:
  1. `request-outline-review`로 4슬라이드 개요를 만들고 사용자 승인을 받는다 (style에 "노란색 포인트" 명시).
  2. 승인 후 `generate-design-structured`로 디자인 생성.
  3. **항상 1:1 정사각형 + 9:16 세로 두 사이즈를 세트로 만든다**: `search-designs`로 방금 만든 디자인의 실제 `design_id`(D로 시작, 11자)를 찾은 뒤, `resize-design`을 두 번 호출 —
     custom 1080x1080 (피드용), custom 1080x1920 (스토리용).
  4. `resize-design`은 Canva 무료 체험 횟수 제한이 있는 기능이다 (`trial_information.uses_remaining`이 0이 되면 더 이상 리사이즈 불가). 막히면 즉시 원장님께 "Canva 유료 플랜 필요" 사실을 알린다 — 조용히 건너뛰지 않는다.
  5. 완성 후 `export-design`으로 이미지(PNG) 또는 PPT로 내보낸다.
- 카드뉴스 텍스트는 본문 요약이 아니라 "한 장에 한 메시지"로 짧게 재구성한다 (문장 아님, 헤드라인 수준).

## 5단계 — 교육적/법적 검수
- `docs/COMPLIANCE_CHECKLIST.md`의 4개 섹션을 항목별로 통과/확인필요/반려로 체크한다.
- 결과를 `output/<날짜>_<학년>/review_report.md`로 저장한다.
- 반려 항목이 있으면 본문을 수정해서 다시 검수한다 (최대 2회 자동 재시도, 이후엔 사람 판단 요청).

## 6단계 — 최종 패키지
`output/<날짜>_<학년>/` 폴더에 아래를 모아 정리한다:
- `post.md` — 최종 본문 + 제목 후보 3개
- `photos_selected.md` — 선택된 사진 목록과 삽입 위치
- `cardnews/` — 카드뉴스 4장 (이미지 또는 PPT)
- `review_report.md` — 5단계 검수 결과
- `SUMMARY.md` — 원장님이 30초 안에 훑어볼 수 있는 요약: 주제 선정 이유, 검수 결과 한 줄,
  발행 가능 여부, 원장님이 직접 확인해야 할 `[확인필요]` 항목 목록

마지막에 사용자에게: 패키지가 준비됐다는 것과, `[확인필요]` 항목이 있다면 그것만 짚어서
알린다. 전체 내용을 채팅에 다시 늘어놓지 않는다 — 파일이 결과물이다.
