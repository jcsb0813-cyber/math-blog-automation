# 수학 릴스 자동 생성

입력: 학년 (예: "중2"). 선택: 단원, 만들 개수 (기본 1개), 직접 준 문제.
출력: `output/<날짜>_<학년>_reel_<단원>/` 폴더마다 `reel.mp4`, `cover.png`, `caption.md`, `spec.json`.

영상 렌더링은 `scripts/make_reel.py`가 한다. Claude의 일은 **좋은 문제와 정확한 풀이를
스펙 JSON으로 쓰는 것**이다. 예시: `examples/reels/중2_연립방정식.json`.

## 1단계 — 문제 고르기
- 사용자가 단원/문제를 줬으면 그대로 쓴다. 아니면 해당 학년의 현재 시기(2학기면 2학기 단원,
  시험기간 직전이면 시험 범위)에 맞는 단원을 고르고, 고른 이유를 한 줄로 밝힌다.
- 릴스용 문제 조건: **암산 또는 2~4줄 풀이로 끝나는 문제**, 문제 문장 60자 안팎,
  그림/그래프가 꼭 필요한 문제는 제외 (텍스트만 렌더링됨).
- "아하" 포인트가 있는 문제 우선 (자주 틀리는 함정, 재밌는 소재, 빠른 풀이 요령).
- 학년 교육과정 밖 개념 사용 금지 (`docs/STYLE_GUIDE.md`의 용어 기준).

## 2단계 — 스펙 작성 (`output/.../spec.json`이 아니라 먼저 스크래치에 작성)
필드:
- `grade`, `unit` (필수) — 화면 상단 태그와 해시태그에 쓰임
- `hook` — 첫 화면 문구. 줄바꿈은 `\n`. 과장 금지 ("상위 1%만", "천재만" 같은 표현 X).
  "N초 안에"를 쓰면 `timing.think`와 숫자를 맞춘다.
- `problem` (필수)
- `hint` (선택) — 풀이 방향만, 답 노출 금지
- `steps` (필수) — 문자열 2~5개. 한 단계 = 한 줄 수식 + 짧은 설명. 줄바꿈은 `\n`.
- `answer` (필수) — 10자 이내 권장 (길면 글자가 작아짐)
- `answer_note` (선택) — 검산 한 줄 또는 함정 포인트
- `timing` (선택) — 기본값 `hook 2.5 / problem 4 / think 5 / hint 3 / step 3 / answer 3 / cta 3.5`초.
  전체 길이 20~40초가 적당.
- `cta`, `cta_sub`, `caption`, `hashtags` (선택) — 비우면 기본 문구 사용

표기 규칙:
- 거듭제곱은 `x²`, `x³` (유니코드), 곱셈 `×`, 나눗셈 `÷`, 분수는 `3/4` 또는 `(x+1)/2`.
- 이모지·특수기호(✔, 💡 등)는 폰트에 없어 네모로 깨진다 — 쓰지 않는다.

## 3단계 — 정답 검증 (건너뛰지 않는다)
- 풀이를 **직접 다시 풀어서** 답이 맞는지 확인한다. 가능하면 `python3 -c`로 대입 검산한다.
- 문제 조건만으로 답이 하나로 정해지는지(조건 누락, 해가 여러 개인지) 확인한다.
- 틀린 풀이가 올라가면 학원 신뢰도에 치명적이다. 확신이 없으면 그 문제는 버리고 다른 문제로 바꾼다.

## 4단계 — 렌더링
1. 미리보기로 레이아웃 확인:
   `python3 scripts/make_reel.py <spec> --preview --out <폴더>`
   → `<폴더>/preview/*.png`를 열어 글자가 잘리거나 넘치지 않는지 본다. 넘치면 문장을 줄인다.
2. 영상 생성: `python3 scripts/make_reel.py <spec>` (기본 출력 경로 사용)
   - 효과음 빼려면 `--no-sound`. 인스타에서 음악을 따로 입힐 거면 빼는 편이 낫다.
   - 처음 실행 시 `pip install -r requirements.txt`, 폰트는 자동 다운로드된다.

## 5단계 — 검수 + 보고
- `docs/COMPLIANCE_CHECKLIST.md`의 1번(광고 표현)과 3번(수학 정확성) 항목을 확인한다.
- 사용자에게 결과 폴더 경로와 영상 길이만 짧게 알리고, `reel.mp4`와 `cover.png`를 파일로 보낸다.
  여러 개를 만들었으면 목록으로. 스펙 전체를 채팅에 다시 늘어놓지 않는다.
- 업로드는 원장님이 직접 한다 (인스타그램 릴스 / 유튜브 쇼츠). `caption.md`를 그대로 붙여넣으면 된다.
